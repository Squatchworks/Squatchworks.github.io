Shadow of Beginnings

Nebula Interactive — Active Development — Unreal Engine 5.6

Unreal Engine 5 C++ Blueprints Lead Gameplay Programmer Commercial In Development

About

Shadow of Beginnings is a commercial indie ARPG developed in Unreal Engine 5.6 by Nebula Interactive. I serve as the lead gameplay and combat programmer, responsible for the core systems that drive the player experience — from moment-to-moment combat feel to AI-driven enemy encounters.

The project is currently in active development with a playable demo as the immediate milestone target. A Steam store page is live and accepting wishlists.

My Contributions

  • Architected and implemented the full combat system in C++ — melee hit detection, damage pipeline, attribute component, and combat state management
  • Built enemy AI from scratch using Unreal's Behavior Tree and Blackboard systems — Bramblekin forest enemy and Cinderhulk stone golem elite with unique patrol, detection, chase, and multi-attack behaviors
  • Implemented spatial audio system for all enemies — 3D attenuation, idle ambience with randomized variation via C++ timer arrays, hit react SFX, attack grunts, aggro triggers, and death audio cleanup
  • Designed and implemented Niagara VFX component architecture for hit impacts, death dissolve effects, and ability FX
  • Built full animation pipeline — hand-keyed idle, walk, hit react, and death animations in Blender and integrated them into UE5 Animation Blueprints with additive layering
  • Implementing Chaos physics fracture destruction for the Cinderhulk death sequence — procedural crumble with lava pool hazard spawner
  • Integrated Enhanced Input system for player controls, pause menu flow, and game state management via custom ACGameLoopManager singleton

Systems Built

  • Combat System — damage pipeline, hit registration, attribute component (HP, team affiliation)
  • Enemy AI — modular Behavior Tree architecture, AIPerception, multi-range attack selection
  • Audio System — spatial 3D attenuation, C++ timer-driven SFX variation, audio component lifecycle management
  • VFX Component — centralized Niagara FX management on base character class
  • Animation Pipeline — Blender rigging and keyframing, UE5 ABP state machines, additive breathing overlay
  • Game Loop Manager — ACGameLoopManager singleton, eGameState enum, state transition system
  • Chaos Destruction — Geometry Collection fracture for Cinderhulk death (in progress)
